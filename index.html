📍 네이버 지도 주소 표시 도구

엑셀 파일의 주소를 네이버 지도에 표시해보세요

사용 방법:

1. 엑셀(.xlsx) 또는 CSV 파일을 업로드하세요

2. 시트가 여러 개면 원하는 시트를 고르세요

3. 주소가 있는 열을 선택하세요

4. 지도에 표시 버튼을 클릭하세요

5. 지도를 확대하면 마커 옆에 이름이 표시됩니다

6. 마커를 누르면 네이버 지도 길찾기로 바로 넘어갑니다
